.. rubric:: Description

This effect/filter alters frame colors in video with pseudocolors.

.. rubric:: Parameters

.. list-table::
   :header-rows: 1
   :width: 100%
   :widths: 20 10 70
   :class: table-wrap

   * - Parameter
     - Value
     - Description
   * - Base component
     - Selection
     - Determines which color channel will be used as base for the effect. Options are **Red** (default), **Green**, **Blue**, and **Alpha**
   * - Preset
     - Selection
     - Select from a number of presets (see list below)
   * - Opacity
     - Integer
     - Set the level of opacity for the pseudo color preset
